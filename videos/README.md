# Папка для видеофайлов серий

Основной план: видео лежат на **Hugging Face (бесплатно)** — заливка скриптом
`tools/upload-hf.sh`, после чего в `assets/js/data.js` вписывается
`hf: { user: 'НИК', repo: 'РЕПО', type: 'datasets' }`. Сюда же можно класть небольшие
файлы для тестов (GitHub/Vercel не потянут гигабайты: лимит 100 МБ на файл в GitHub
и 100 МБ на весь деплой Hobby в Vercel).

Имена файлов (плеер подхватит их автоматически):

    s01e01.mp4 … s01e20.mp4
    s02e01.mp4 … s02e16.mp4

Формат: MP4, H.264 + AAC (лучшая совместимость с Android TV).

Для больших объёмов (14 ГБ и более) используйте внешнее хранилище
(Cloudflare R2 / Backblaze B2 / Bunny) и укажите base-URL в `assets/js/data.js`
в поле `videoBase` — подробности в README.md проекта.

Пока файлов нет, плеер стоит в режиме ожидания: контролы погашены, ошибок нет.
