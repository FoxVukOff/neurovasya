# Папка для видеофайлов серий

Основной план: видео лежат на **Hugging Face (бесплатно)** и заливаются вручную
(репозиторий уже вшит в `assets/js/data.js`: FoxVuk/dhhadhshjjdkahddas). Сюда же можно класть небольшие
файлы для тестов (GitHub/Vercel не потянут гигабайты: лимит 100 МБ на файл в GitHub
и 100 МБ на весь деплой Hobby в Vercel).

Имена файлов, которые понимает плеер (первые два — фактический шаблон хранилища):

    1_1.mkv … 1_20.mkv      (сезон 1, уже загружено на Hugging Face)
    2_1.mkv … 2_9.mkv      (сезон 2 — серии 1–9 уже загружены)
    2_1.mp4 … 2_9.mp4      (MP4-копии с подчёркиванием)
    2.7.mp4                (дополнительное фактическое имя для 2×07)
    s01e01.mp4 … s02e16.mp4 (альтернатива после конвертации MKV → MP4)

Формат: MP4, H.264 + AAC (лучшая совместимость с Android TV).

Для больших объёмов (14 ГБ и более) используйте внешнее хранилище
(Cloudflare R2 / Backblaze B2 / Bunny) и укажите base-URL в `assets/js/data.js`
в поле `videoBase` — подробности в README.md проекта.

Пока файлов нет, плеер стоит в режиме ожидания: контролы погашены, ошибок нет.
