# НЕЙРОВАСЯ · сайт для Vercel

Комедия ТНТ: **1 сезон — 2025, 20 серий** · **2 сезон — с 02.11.2026, 16 серий (на Okko по 3 серии в день: 2–7 ноября)**.
Статический сайт без сборки в официальном пресс-стиле: афиша с ключевыми фактами,
статус-борд состояния сайта, каталог из 36 отдельных страниц серий, расписание эфира
по неделям, блок актёров и ролей, справки и 404. Пока видеофайлы не загружены,
страница серии показывает аккуратную **статус-карточку** (без заглушек, фейковых
контролов и ошибок), а когда файл серии появляется в хранилище Hugging Face —
плеер активируется сам, без перезагрузки страницы.

## Возможности
- отдельная страница на каждую серию: `/season-1/episode-01` … `/season-2/episode-16`;
- **статус-карточки вместо заглушки**: играть нечего — чистая плашка «Видео серии
  ещё не загружено» (или «Формат не поддержан», «Серия ещё не вышла» — по ситуации)
  с кнопками «последняя вышедшая» и «на главную»; никаких фейковых контролов.
  «Дозор» раз в 75 секунд проверяет хранилище и активирует плеер с той же страницы;
- **умный выбор формата MP4/MKV**: плеер перебирает кандидатов, реально пробуя
  играбельность каждого на устройстве; сыгравший формат запоминается и в следующий
  раз пробуется первым, а в топбаре появляется чип формата (MP4/MKV);
- кастомный плеер (после активации): перемотка (мышь/тач/клавиши/цифры пульта), ±10 с,
  скорость ×0.75–×2, громкость, полноэкранный режим, буферизация, тултип времени;
- **автопереход на следующую серию** с обратным отсчётом 12 с (отключается тумблером);
- **сохранение последней серии и позиции** в localStorage: кнопка «Продолжить» на главной,
  тост «Продолжить с MM:SS», отметки «просмотрено» и прогресс-бары в сетке серий;
- **сброс отметок просмотра**: кнопка «Сбросить отметку» на странице каждой серии
  и «Сбросить весь прогресс» на главной (двухшаговое подтверждение, настройки
  плеера — скорость, громкость, формат — не трогают);
- **план загрузки 2 сезона** (настройка `s2plan` в `assets/js/data.js`):
  2×01–2×06 уже на серверах и играют как 1 сезон; 2×07–2×09 помечены «скоро
  загрузится» — плеер караулит файл и включится сам; 2×10–2×16 ещё не вышли
  на Okko — плашка «Серия ещё не вышла» с датой, в день выхода плеер оживёт сам;
- **настойчивый авторетрай**: «не открылось» на телевизоре чаще значит «не успело
  загрузиться», поэтому плеер не сдаётся: повторяет попытки запуска с нарастающей
  паузой (5 → 10 → 20 → 40 → 60 с и далее каждую минуту) до победного; при обрыве
  посреди просмотра перезапускает тот же файл с той же позиции (до 4 раз тихо,
  с тостом); карточка «Видео пока не запускается» честно показывает счётчик попыток;
- **«чистый экран»**: кнопка с глазом в пульта-строке прячет верхнюю панель, нижние
  контролы и полоску прогресса (удобно с пульта Android TV); возврат — любой тычок
  или любая кнопка, первое нажатие только возвращает интерфейс и видео не трогает;
- **Android TV / D-pad**: пространственная навигация стрелками, OK = пауза/играть,
  «Назад» = выход, медиа-кнопки пультов, крупные фокус-рамки, увеличенный UI;
- серии 2 сезона «знают» свой выход по графику Okko (3 серии в день): будущие показывают
  плашку «Серия ещё не вышла», сегодняшняя — бейдж «сегодня на Okko»;
- официальная подача: афиша с постерами ТНТ и ключевыми фактами, технический статус-борд,
  расписание выхода 2 сезона на Okko по выпускам (6 пачек по 3 серии), блок актёров и ролей, статус-панель
  на странице серии (эфир / видео / плеер), хлебные крошки, солидный подвал;
- SEO/OG-теги на каждой странице, манифест, 404, кэш-заголовки в `vercel.json`.

## Деплой на Vercel (ваш рабочий процесс)
1. Скачайте папку `neurovasya` (или клонируйте репозиторий).
2. Запушьте папку в GitHub-репозиторий (внутри только лёгкие файлы сайта — видео туда НЕ надо).
3. На vercel.com: **Add New… → Project → Import** вашего репозитория.
   Framework Preset: **Other**, Output Directory: оставить пустым (корень папки).
4. Deploy. Готово: `cleanUrls` из `vercel.json` даст красивые адреса серий.

Локальный просмотр без Vercel: `python3 tools/preview_server.py` → http://localhost:8000
(сервер эмулирует cleanUrls Vercel: `/season-1/episode-01` → `episode-01.html`).

## КУДА ЗАГРУЗИТЬ 14 ГБ ВИДЕО (важно!)
**Не кладите видео в GitHub и в деплой Vercel.** Ограничения: GitHub — 100 МБ на файл,
Vercel CLI/деплой — 100 МБ исходников на Hobby (1 ГБ на Pro). Vercel — это код и лёгкая
статика, а не видеохостинг. Сайт умеет играть видео с любого внешнего хранилища:
плеер сам проверяет кандидатов на файл и включает реальное видео; пока файла нет — показывает статус-карточку.

### Вариант 1 — Hugging Face (бесплатно, выбран по умолчанию)
HF даёт бесплатное публичное хранилище с LFS и поддержкой range-запросов — видео
стримится прямо оттуда, доплачивать за трафик не нужно.
**Репозиторий уже создан и вшит в сайт:** публичный датасет
[FoxVuk/dhhadhshjjdkahddas](https://huggingface.co/datasets/FoxVuk/dhhadhshjjdkahddas),
конфигурация в `assets/js/data.js` (`hf: { user: 'FoxVuk', repo: 'dhhadhshjjdkahddas', … }`).
Пока файлы долитятся, страница показывает карточку «Видео серии ещё не загружено» (без ошибок и фейкового воспроизведения) и сама переключится на настоящее видео, как только файл появится — даже без перезагрузки страницы.

Фактические имена файлов уже в репозитории: **1_1 … 1_20** и **2_1 … 2_6** —
каждая серия в `.mkv` и `.mp4` (`1_1` = сезон 1, серия 1). Плеер ищет именно такие
имена и ждёт **2_7 … 2_16**; прежние шаблоны `s01e01.mp4` тоже понимаются.

> **План загрузки 2 сезона** (настройка `s2plan = { awaitingUpload: [7, 8, 9], locked: [] }`
> в `assets/js/data.js`): серии **2_1 … 2_6** уже загружены и играют как 1 сезон
> (умный выбор MP4/MKV с памятью формата). Серии **7–9** в списке `awaitingUpload` —
> «скоро загрузится на серверы»: их страницы караулят файлы `2_N.mp4`/`2_N.mkv` и включат
> видео сами, даже без перезагрузки страницы. Серии **10–16** ещё не вышли на Okko —
> плашка «Серия ещё не вышла» с датой; в день выхода плеер сам начнёт искать файл.
> Как зальёте 7–9 — уберите их из `awaitingUpload`, затем `python3 tools/build.py` и деплой.

#### MKV и браузеры (важно)
- Desktop Chrome / Chromium обычно играет MKV (H.264 внутри) напрямую — серии заработают.
- **Android TV (WebView/Chromium), Firefox и Safari контейнер Matroska, как правило,
  не тянут**, а HEVC/AC3 могут не открыться даже в Chrome. Для телевизора нужны
  MP4-копии (H.264 + AAC + faststart).
- Если файл есть, но не играется, страница честно покажет карточку «Формат не поддержан»
  с именем файла — без ошибок плеера; сыгравший на устройстве формат запоминается.
- Лечится конвертацией без потери качества видео (быстро, копирует видеопоток):
  ```bash
  ffmpeg -i 1_1.mkv -c:v copy -c:a aac -movflags +faststart s01e01.mp4
  # если видео HEVC — уже с перекодированием:
  ffmpeg -i 1_1.mkv -c:v libx264 -crf 23 -preset veryfast -c:a aac -movflags +faststart s01e01.mp4
  ```
  Залитые рядом `s01e01.mp4` сайт подхватит автоматически (mp4 в списке кандидатов первый).

#### Если не играет на Android TV (и в Safari/Firefox)
Браузеры Android TV — это Chromium/WebView **без контейнера Matroska**, поэтому MKV там
не открывается, хотя на ПК в Chrome играет. Решение — MP4-копии рядом с MKV:
Заливка — вручную (web-интерфейс HF drag-and-drop или `hf upload`): файлы кладутся в корень
репозитория. Требования, чтобы плеер и Android TV работали сразу:
- имена `1_1.mp4 … 1_20.mp4` (2 сезон — `2_1.mp4 …`);
- `-movflags +faststart` при конвертации (иначе старт и перемотка тормозят);
- звук AAC (не AC3), видео копировать без перекодирования (`-c:v copy`), если внутри H.264;
- субтитры не тащить (`-sn`).
Дальше сайт сам выбирает файл под устройство: Android TV/Safari/Firefox получат MP4,
desktop Chrome — MP4 или MKV (что играбельно). Страницы, где playable-версии ещё нет,
показывают честный статус «нужна MP4-версия» вместо ошибок. Конвертация и заливка —
вашими инструментами; от сайта нужны только имена файлов и флаги из списка выше.
Плеер соберёт ссылки вида `https://huggingface.co/datasets/НИК/РЕПО/resolve/main/s01e01.mp4`
и подхватит все 36 серий автоматически. Нюансы: скорость отдачи зависит от HF-CDN
(обычно хватает для 720p–1080p), приватный репозиторий для анонимного плеера не подойдёт.

### Вариант 2 — свой CDN (если захотите больше контроля/скорости)
| Вариант | Цена ~ за 14 ГБ | Трафик | Как залить |
|---|---|---|---|
| **Cloudflare R2** | ≈ $0.22/мес | **бесплатно** | `rclone copy` (см. ниже) или dashboard |
| **Backblaze B2 + Cloudflare** | ≈ $0.09/мес | бесплатно через CF | `rclone copy` |
| **Bunny Storage + CDN** | ≈ $0.14/мес + трафик | ~€0.005/ГБ | web-UI или S3-API/rclone |
| **Vercel Blob** (всё в Vercel) | тариф Pro + оплата storage/egress | платно | dashboard / @vercel/blob |

```bash
# пример для R2 / B2 через rclone (имена файлов те же: s01e01.mp4 …)
rclone copy ./серии/ remote:neurovasya/ --progress --transfers 4
```

### Шаг 2. Сказать сайту, где видео
Откройте `assets/js/data.js` и выберите один из путей:
```js
// Hugging Face (бесплатно, по умолчанию):
hf: { user: 'ВАШ_НИК', repo: 'neurovasya-videos', type: 'datasets' },
// или любой другой CDN:
videoBase: 'https://pub.ваш-бакет.dev/neurovasya/',
```
Либо точечно для любой серии:
```js
NV.VIDEO_SRC['1:01'] = 'https://example.com/sezon1/seria01.mp4';
```
Или положите небольшие файлы прямо в папку `videos/` сайта (имена `s01e01.mp4`…) —
тогда `videoBase` трогать не нужно. Формат: MP4 (H.264 + AAC) — лучше всего для ТВ.

Пока файлов нет — ничего делать не нужно: страницы серий показывают режим ожидания
с плашкой «ожидание видеофайла · плеер в режиме ожидания».

## Управление
| Действие | Мышь | Клавиатура | Пульт Android TV |
|---|---|---|---|
| Пауза/играть | клик по видео / кнопка | `Space`, `K`, `Enter` | `OK` |
| Перемотка ±10 с | кнопки, таймлайн | `←` `→` (на таймлайне `Shift` = ±60) | `←` `→` |
| К проценту времени | — | цифры `0–9` | цифры |
| Следующая серия | кнопка ⏭ | `N` | `MediaNext` |
| Громкость / звук | слайдер | `M` | стрелки на слайдере |
| Весь экран | кнопка | `F` | — |
| Навигация по сайту | — | `Tab` / стрелки | стрелки (D-pad), `OK` |
| Назад | — | `Esc` | кнопка «Назад» |

## Правки контента
- даты/число серий/расписание — `assets/js/data.js`;
- тексты главной и описания — `tools/build.py`, затем `python3 tools/build.py`;
- постеры — `assets/img/` (сейчас официальные промо-изображения ТНТ).

Сайт неофициальный, фанатский. Видео появится позже; права на сериал «Нейровася»
принадлежат ТНТ и правообладателям.
