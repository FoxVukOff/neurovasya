# НЕЙРОВАСЯ · сайт для Vercel

Комедия ТНТ: **1 сезон — 2025, 20 серий** · **2 сезон — с 02.11.2026, 16 серий (пн–чт, 20:00)**.
Статический сайт без сборки в официальном пресс-стиле: афиша с ключевыми фактами,
статус-борд состояния сайта, каталог из 36 отдельных страниц серий, расписание эфира
по неделям, блок актёров и ролей, справки и 404. Пока видеофайлы не загружены,
плеер стоит в **режиме ожидания** (ничего не воспроизводит и не выдаёт ошибок),
а когда файл серии появляется в хранилище Hugging Face — активируется сам,
без перезагрузки страницы.

## Возможности
- отдельная страница на каждую серию: `/season-1/episode-01` … `/season-2/episode-16`;
- **режим ожидания плеера**: пока файла нет — контролы погашены, время прочерками,
  никаких ошибок и фейкового воспроизведения; «дозор» раз в 75 секунд проверяет
  хранилище и при появлении файла активирует плеер с той же страницы;
- кастомный плеер (после активации): перемотка (мышь/тач/клавиши/цифры пульта), ±10 с,
  скорость ×0.75–×2, громкость, полноэкранный режим, буферизация, тултип времени;
- **автопереход на следующую серию** с обратным отсчётом 12 с (отключается тумблером);
- **сохранение последней серии и позиции** в localStorage: кнопка «Продолжить» на главной,
  тост «Продолжить с MM:SS», отметки «просмотрено» и прогресс-бары в сетке серий;
- честная диагностика формата: файл есть, но браузер не тянет MKV/кодек —
  страница сообщает об этом и подсказывает конвертацию, вместо ошибок плеера;
- **Android TV / D-pad**: пространственная навигация стрелками, OK = пауза/играть,
  «Назад» = выход, медиа-кнопки пультов, крупные фокус-рамки, увеличенный UI;
- серии 2 сезона «знают» свой эфир: будущие показывают плашку «Серия ещё не вышла»,
  сегодняшняя — бейдж «сегодня в 20:00»;
- официальная подача: афиша с постерами ТНТ и ключевыми фактами, технический статус-борд,
  расписание эфира 2 сезона по неделям (пн–чт), блок актёров и ролей, статус-панель
  на странице серии (эфир / видео / плеер), хлебные крошки, солидный подвал;
- SEO/OG-теги на каждой странице, манифест, 404, кэш-заголовки в `vercel.json`.

## Деплой на Vercel (ваш рабочий процесс)
1. Скачайте папку `neurovasya` (или клонируйте репозиторий).
2. Запушьте папку в GitHub-репозиторий (внутри только лёгкие файлы сайта — видео туда НЕ надо).
3. На vercel.com: **Add New… → Project → Import** вашего репозитория.
   Framework Preset: **Other**, Output Directory: оставить пустым (корень папки).
4. Deploy. Готово: `cleanUrls` из `vercel.json` даст красивые адреса серий.

Локальный просмотр без Vercel: `python3 tools/preview_server.py` → http://localhost:8000
(сервер эмулирует cleanUrls Vercel: `/season-1/episode-01` → `episode-01.html`).

## КУДА ЗАГРУЗИТЬ 14 ГБ ВИДЕО (важно!)
**Не кладите видео в GitHub и в деплой Vercel.** Ограничения: GitHub — 100 МБ на файл,
Vercel CLI/деплой — 100 МБ исходников на Hobby (1 ГБ на Pro). Vercel — это код и лёгкая
статика, а не видеохостинг. Сайт умеет играть видео с любого внешнего хранилища:
плеер сам проверяет кандидатов на файл и включает реальное видео; пока файла нет — стоит в режиме ожидания.

### Вариант 1 — Hugging Face (бесплатно, выбран по умолчанию)
HF даёт бесплатное публичное хранилище с LFS и поддержкой range-запросов — видео
стримится прямо оттуда, доплачивать за трафик не нужно.
**Репозиторий уже создан и вшит в сайт:** публичный датасет
[FoxVuk/dhhadhshjjdkahddas](https://huggingface.co/datasets/FoxVuk/dhhadhshjjdkahddas),
конфигурация в `assets/js/data.js` (`hf: { user: 'FoxVuk', repo: 'dhhadhshjjdkahddas', … }`).
Пока файлы долитятся, плеер стоит в режиме ожидания (без ошибок и фейкового воспроизведения) и сам переключится на настоящее видео, как только файл появится — даже без перезагрузки страницы.

```bash
# Заливка (файлы сезона в папке ./серии):
bash tools/upload-hf.sh FoxVuk dhhadhshjjdkahddas ./серии
```
Фактические имена файлов 1 сезона уже в репозитории: **1_1.mkv … 1_20.mkv**
(`1_1` = сезон 1, серия 1). Плеер ищет именно такие имена, а для 2 сезона ждёт
**2_1.mkv … 2_16.mkv**; прежние шаблоны `s01e01.mp4` тоже понимаются.

#### MKV и браузеры (важно)
- Chrome / Chromium и браузеры большинства Android TV проигрывают MKV напрямую,
  если внутри H.264 + AAC/AC3 — серии просто заработают.
- Firefox и Safari контейнер Matroska не поддерживают, а HEVC/AC3 могут не открыться
  даже в Chrome. Тогда страница честно покажет статус «файл найден, но этот браузер
  не может воспроизвести формат» (красный индикатор в статус-панели) — без ошибок.
- Лечится конвертацией без потери качества видео (быстро, копирует видеопоток):
  ```bash
  ffmpeg -i 1_1.mkv -c:v copy -c:a aac -movflags +faststart s01e01.mp4
  # если видео HEVC — уже с перекодированием:
  ffmpeg -i 1_1.mkv -c:v libx264 -crf 23 -preset veryfast -c:a aac -movflags +faststart s01e01.mp4
  ```
  Залитые рядом `s01e01.mp4` сайт подхватит автоматически (они в списке кандидатов первыми после mkv).
Плеер соберёт ссылки вида `https://huggingface.co/datasets/НИК/РЕПО/resolve/main/s01e01.mp4`
и подхватит все 36 серий автоматически. Нюансы: скорость отдачи зависит от HF-CDN
(обычно хватает для 720p–1080p), приватный репозиторий для анонимного плеера не подойдёт.

### Вариант 2 — свой CDN (если захотите больше контроля/скорости)
| Вариант | Цена ~ за 14 ГБ | Трафик | Как залить |
|---|---|---|---|
| **Cloudflare R2** | ≈ $0.22/мес | **бесплатно** | `rclone copy` (см. ниже) или dashboard |
| **Backblaze B2 + Cloudflare** | ≈ $0.09/мес | бесплатно через CF | `rclone copy` |
| **Bunny Storage + CDN** | ≈ $0.14/мес + трафик | ~€0.005/ГБ | web-UI или S3-API/rclone |
| **Vercel Blob** (всё в Vercel) | тариф Pro + оплата storage/egress | платно | `tools/upload-blob.mjs` |

```bash
# пример для R2 / B2 через rclone (имена файлов те же: s01e01.mp4 …)
rclone copy ./серии/ remote:neurovasya/ --progress --transfers 4
```

### Шаг 2. Сказать сайту, где видео
Откройте `assets/js/data.js` и выберите один из путей:
```js
// Hugging Face (бесплатно, по умолчанию):
hf: { user: 'ВАШ_НИК', repo: 'neurovasya-videos', type: 'datasets' },
// или любой другой CDN:
videoBase: 'https://pub.ваш-бакет.dev/neurovasya/',
```
Либо точечно для любой серии:
```js
NV.VIDEO_SRC['1:01'] = 'https://example.com/sezon1/seria01.mp4';
```
Или положите небольшие файлы прямо в папку `videos/` сайта (имена `s01e01.mp4`…) —
тогда `videoBase` трогать не нужно. Формат: MP4 (H.264 + AAC) — лучше всего для ТВ.

Пока файлов нет — ничего делать не нужно: страницы серий показывают режим ожидания
с плашкой «ожидание видеофайла · плеер в режиме ожидания».

## Управление
| Действие | Мышь | Клавиатура | Пульт Android TV |
|---|---|---|---|
| Пауза/играть | клик по видео / кнопка | `Space`, `K`, `Enter` | `OK` |
| Перемотка ±10 с | кнопки, таймлайн | `←` `→` (на таймлайне `Shift` = ±60) | `←` `→` |
| К проценту времени | — | цифры `0–9` | цифры |
| Следующая серия | кнопка ⏭ | `N` | `MediaNext` |
| Громкость / звук | слайдер | `M` | стрелки на слайдере |
| Весь экран | кнопка | `F` | — |
| Навигация по сайту | — | `Tab` / стрелки | стрелки (D-pad), `OK` |
| Назад | — | `Esc` | кнопка «Назад» |

## Правки контента
- даты/число серий/расписание — `assets/js/data.js`;
- тексты главной и описания — `tools/build.py`, затем `python3 tools/build.py`;
- постеры — `assets/img/` (сейчас официальные промо-изображения ТНТ).

Сайт неофициальный, фанатский. Видео появится позже; права на сериал «Нейровася»
принадлежат ТНТ и правообладателям.
